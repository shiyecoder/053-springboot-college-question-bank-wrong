# 设计系统 · 高校智能题库与错题本系统（053）

## 1. 视觉方向
学术紫主色，题目区留白充足，选项使用描边卡片；诊断部分用雷达图与进度条，不使用花哨插画。
整体气质：安静的纸质试卷感 + 清晰的数据层。圆角克制（8-10px），阴影仅用于抽屉/弹层。

## 2. 色彩
| 用途 | 色值 | 用法 |
|---|---|---|
| 主色 primary | `#4B3F72` | 顶部栏、主按钮、当前菜单、关键数字、雷达图主线 |
| 辅助 sub | `#7A6BA8` | 次级按钮、筛选选中态、普通图表系列 |
| 强调 accent | `#E0A458` | 待办数量、重点提示、图表对比系列、进度条警示档 |
| 页面背景 | `#F5F6F7` | 内容区背景；表格/表单用白色容器 `#FFFFFF` |
| 边框 | `#E4E7EB` / 分割线 `#EEF0F2` | 卡片边框、表头下边线 |
| 正文 | `#1F2933` | 标题与正文 |
| 次要文字 | `#5B6770` | 说明、单位、表头 |
| 成功 | `#2B7955` | 已掌握、已通过、启用 |
| 警告 | `#8A5A12`（底 `#FDF3E3`） | 待审核、薄弱、复习中 |
| 危险 | `#B02A37` | 驳回、严重薄弱、删除 |

状态不可只靠颜色表达：每个状态标签同时输出中文文案，图表配图例文字。

## 3. 字体阶梯
| 层级 | 字号/行高 | 字重 | 用途 |
|---|---|---|---|
| H1 页面标题 | 20 / 1.4 | 700 | 门户页头、抽屉标题 |
| H2 卡片标题 | 14 / 1.4 | 600 | 卡片头部 |
| 正文 | 13 / 1.7 | 400 | 表格、表单、说明 |
| 题目正文 | 15~16 / 1.9 | 400 | 答题页题干 |
| 辅助 | 12 / 1.6 | 400 | 表头、单位、空状态 |
| 数字 | 26 / 1.2 | 700 | KPI 数值，`font-variant-numeric: tabular-nums` |

字体族：`"PingFang SC","Microsoft YaHei",system-ui,sans-serif`；数字统一等宽对齐。

## 4. 圆角 / 间距 / 阴影
- 圆角：卡片 10px、按钮与输入 7px、标签 5px、头像与选项圆标 50%
- 间距刻度：4 / 8 / 12 / 16 / 24（内容区外边距固定 24px）
- 卡片间距 16px，卡片内 padding 16px
- 阴影：`0 8px 30px rgba(20,20,40,.12)` 仅用于右侧抽屉与弹窗

## 5. 布局骨架
- 管理端：220px 左侧菜单 + 56px 顶栏 + 自适应内容区；菜单折叠保留图标
- 门户端（学生）：60px 顶部导航 + 1240px 居中内容区，去掉侧边栏，视觉上明显区别于后台
- 顶栏只放面包屑、消息、帮助、头像，不放宣传内容
- 首页 8 个 KPI 用 4×2 紧凑网格，图表区高度 196/150px，1440×900 一屏不出滚动条

## 6. 图表规范（ECharts）
- 系列色序：`#4B3F72` `#7A6BA8` `#E0A458` `#2B7955` `#98A2B3`
- 雷达图：面积填充 `rgba(75,63,114,.18)`，网格线 `#E4E7EB`，轴标签 11px `#5B6770`
- 折线：`smooth:true`，`symbol:'circle'`，`symbolSize:5`，双轴时右轴为百分比
- 柱状：`barMaxWidth:18`，圆角 `[3,3,0,0]`
- 所有图表带图例文字，tooltip 统一 `trigger:'axis'`
