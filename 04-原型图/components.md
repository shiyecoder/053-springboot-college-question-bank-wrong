# 组件规范（053）

## 按钮
| 类型 | 高度 | 内边距 | 底色 | 边框 | 文字 |
|---|---|---|---|---|---|
| 主按钮 | 32 | 0 14 | `#4B3F72` | 同底 | `#fff` |
| 次按钮 | 32 | 0 14 | `#fff` | `#D6DAE0` | `#1F2933` |
| 强调按钮 | 32 | 0 14 | `#E0A458` | 同底 | `#3A2A10` |
| 危险按钮 | 32 | 0 14 | `#fff` | `#B02A37` | `#B02A37` |
| 小号 | 26 | 0 9 | 同上 | 同上 | 12px |

hover：次按钮边框转 `#7A6BA8`、文字转主色；主按钮加深至 `#3C3260`。
表格行内最多 1 个查看 + 2 个高频操作，其余收进「更多」；危险操作二次确认。

## 表单
- 标签宽 110px 右对齐，单列输入宽 360~520px，搜索下拉宽 180~240px
- 输入高 32px，边框 `#D6DAE0`，聚焦主色 + `0 0 0 3px rgba(75,63,114,.10)`
- 必填星号前置，错误态边框 `#B02A37` 并在下方给出具体字段提示
- 日期区间、人员、组织、字典、级联一律用对应组件，不用文本框代替

## 表格
- 表头：12px `#5B6770`，背景 `#FAFBFC`，下边线 `#E4E7EB`，不固定列宽按内容自适应
- 单元格：13px，行高 42px，纵向居中，`line-height:1.6`
- hover 行底色 `#FBFAFD`；超长文本省略 + tooltip
- 列表页必须服务端分页，右下角保留总数 + 页码 + 每页条数

## 状态标签
高 22px、圆角 5px、11px 字重 600、1px 描边。五档：成功（已掌握/已入库/启用）、
信息（待审核中的中性态/使用中/单选）、警告（待审核/薄弱/复习中）、危险（已驳回/严重薄弱）、
灰（草稿/已归档/已停用）。标签必带中文，不靠颜色单独表意。

## 卡片
白色底、1px `#E4E7EB`、圆角 10px；头部 14px 标题 + 12px 副说明 + 右侧操作区，
头部下边线 `#EEF0F2`；内容区 padding 16px。空状态说明原因与下一步操作。

## 抽屉 / 弹窗
- 右侧抽屉宽 420px（复杂表单 560px），顶部标题 + 摘要，底部固定操作条
- 审核、流转、错题详情统一用抽屉，避免来回切页
- 弹窗宽 640px（表单）/ 880px（预览），遮罩 `rgba(20,20,40,.35)`

## 分页
右对齐；当前页主色实底白字，其余描边；含「共 N 条」与每页条数选择（10/20/50）。

## 进度与图表
- 进度条高 8px、圆角 4px、轨道 `#EDEFF2`；<50 用危险色，50~70 用强调色，≥85 用成功色
- 雷达图/折线/柱状尺寸与配色见 design-system.md 第 6 节

## 响应式
<768px：侧边栏转抽屉，筛选折叠为底部面板，表格转信息卡片（编号/状态/时间/负责人），
点击区 ≥44px，底部固定操作条不遮挡分页。
